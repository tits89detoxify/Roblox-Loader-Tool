## FAQ

### What is XCutors?

XCutors is a curated collection of popular Windows desktop executors for Roblox, bundled with a universal loader for convenient access.

### Is it safe to use?

Our package is provided for educational and customization purposes. Users should always be aware of the risks of using third-party tools and adhere to Roblox's Terms of Service.

### How do I update the executors?

The universal loader will check for updates and notify you when a new version for any included executor is available. You can then update directly through the interface.

### My anticomponent flagged a file. What do I do?

Some security software may falsely flag such tools. You can temporarily disable your anticomponent or add an exception for the XCutors folder if you trust the source.

### Can I use this on Mac or Linux?

No. XCutors is designed exclusively for Windows desktop operating systems.

### Where can I find scripts to run?

You can find community-shared scripts on various forums and websites. Always exercise caution and scan script content before running it.

### An executor isn't working with a specific game. Why?

Game developers can update their anti-enhance measures. If an executor stops working, it likely needs an update from its respective developer, which we would reflect in XCutors when available.
